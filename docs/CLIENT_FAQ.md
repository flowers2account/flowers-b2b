# Памятка клиента «Цветы Уральска»

Оптовый магазин цветов и расходных материалов: каталог и корзина доступны без предварительного входа, PIN-код нужен для личного кабинета и повторного входа.

## 1. Как стать клиентом и получить доступ

Собрать корзину и перейти к оформлению можно без предварительной регистрации. Клиент создаётся или обновляется по номеру телефона при оформлении заказа. PIN-код отправляется в WhatsApp после оформления и нужен для будущего входа в личный кабинет.

Получить доступ к личному кабинету можно тремя путями:

- **Заявка на сайте** — на странице входа вкладка «Получить доступ» (или форма на странице «О нас»): указываете имя и номер телефона.
- **WhatsApp** — написать на +7 700 978 8467.
- **Звонок** — +7 700 978 8467.

Если клиент оформляет заказ впервые, система сама сохраняет клиента и отправляет PIN в WhatsApp. Если доступ запрашивается отдельно, его открывает менеджер; после подтверждения PIN-код приходит на ваш номер в WhatsApp.

## 2. PIN-вход

- Для входа в личный кабинет клиент вводит номер телефона (формат +7XXXXXXXXXX) и PIN (4–6 цифр).
- Забыли PIN → на странице входа кнопка «Забыли PIN?» → оставляете номер → менеджер присылает новый PIN в WhatsApp.
- PIN можно сменить самостоятельно в личном кабинете после входа.
- Есть галочка «Запомнить меня» — сессия сохраняется в браузере.

## 3. Как оформить заказ

1. В каталоге добавляете товары в корзину без входа (количество — кратно упаковке товара).
2. В корзине жмёте «Оформить заказ» → страница оформления.
3. Выбираете способ получения (самовывоз / доставка), указываете получателя (имя, телефон, e-mail для чека).
4. Система создаёт или обновляет клиента по номеру телефона и отправляет PIN в WhatsApp для будущего входа.
5. Жмёте «Оплатить заказ» → переход на защищённую страницу банка (Halyk ePay, 3-D Secure), карта вводится на стороне банка.
6. После успешной оплаты заказ создаётся, менеджер получает уведомление и связывается для подтверждения и согласования получения/доставки.

Оплата — сразу онлайн (не «сначала подтверждение менеджером, потом оплата»). Товары резервируются на 30 минут на время оплаты. Самовывоз — в день оплаты после того, как менеджер подтвердит готовность (сообщит в WhatsApp).

## 4. Доставка (сборная / shared-load схема)

| Вариант | Условия |
|---------|---------|
| Самовывоз | Бесплатно. Склад в Уральске, ул. Амангельды Каримуллина, 11. В день оплаты после подтверждения. |
| Доставка по Уральску | В день заказа или на следующий. Стоимость — индивидуально. + скидка 1% при заказе через сайт. |
| Актобе и Атырау | Сборный рейс раз в неделю — бесплатно при заказе от 50 000 ₸. Меньше суммы — по согласованию с менеджером. |

Стоимость доставки считается индивидуально (зависит от состава и адреса), оплачивается отдельно, менеджер согласует при подтверждении. Отправка — только в пределах Казахстана.

## 5. Оплата

- **Картой онлайн** через Halyk Bank · ePay — Visa / Mastercard / UnionPay, 3-D Secure, без комиссии для покупателя. Основной (и пока единственный на сайте) способ.
- **По счёту для организаций** (ИП/ТОО) — помечено «скоро», на сайте пока недоступно. Для клиентов Halyk — без комиссии и рассрочка через OnlineDuken (в планах).
- **Наличные при самовывозе** на сайте не предусмотрены (оплата проходит онлайн до выдачи). Нестандартные способы — по договорённости с менеджером.

## 6. Минимальный заказ / условия опта

- Жёсткого порога для оформления заказа нет — можно заказать любую сумму.
- Порог 50 000 ₸ действует только для бесплатной сборной доставки в Актобе/Атырау.
- Количество кратно упаковке товара (шаг задаётся для каждой позиции).
- Скидка 1% — при заказе через сайт с самовывозом или доставкой по Уральску.
