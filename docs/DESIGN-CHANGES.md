# DESIGN-CHANGES.md — Журнал изменений интерфейса (27.05–06.06.2026)

> Актуально на: 06.06.2026
> Источник истины: git log + текущий код. Дополняет `docs/UX_DESIGN_BRIEF.md` (бриф) — здесь фактические изменения за период.

---

## 1. Типографика и бренд

- **Шрифты** (`249b35f`): **Lora** (serif) на логотипе и заголовках, **Golos Text** на карточках/лейблах. Playfair Display и Cormorant удалены. Эксперимент «Golos везде» откатан (`d9ac0a2`) — заголовки остаются на Lora.
- **Логотип** (`a2dfa15`): плейсхолдер заменён на официальное лого-изображение.

## 2. Футер и юридический слой

- **SiteFooter** (`d5d9f73`): тёплая фирменная палитра (`#211A1E`), градиентная линия, реквизиты, чипы платёжных систем. Эксперимент с CtxBar в футере откатан (`ce07d7e`).
- Полный публичный правовой слой (оферта, политики, оплата/доставка/возврат, контакты) — см. `docs/PAYMENTS.md` §8 и `src/config/company.ts`.
- Слоган-баннер `AboutBlock` убран из каталога (`bd3011b`); `AboutBlock` остался на главной (сворачивается на мобиле).

## 3. Страница товара (`/product/[id]`)

- Редизайн страницы товара (`1d8e33a`) + генератор описаний для срезки.
- Галерея: лента из 4 фото + стрелки (`2312038`), **лайтбокс** по клику, кнопка «лайк» в углу фото (`4779dd2`).
- Десктоп: вкладки «Описание/Характеристики» перенесены в правую колонку, галерея sticky (`caf162d`).
- Степпер + «В корзину» в одну строку над описанием.
- **Похожие товары**: горизонтальная карусель со стрелками (`4a926c3`) + бесконечная подгрузка при скролле (`ec522c4`).
- Хлебные крошки кликабельны (Каталог / Категория / Подкатегория) — `aa7452b`.
- Латинское имя сорта под `display_name` в карточке и DetailPanel (`527cf88`).
- Ферма и `weight_gram` показываются в GridCard/DetailPanel (`5debf5c`).

## 4. Мобильный UX

- Клик по карточке открывает **bottom sheet** деталей вместо перехода на страницу (`9556357`). (Ранее был эксперимент с навигацией на страницу — `a9cd393`.)
- **Свайпы**: свайп-вниз закрывает фильтр/детали (`ea46d49`, нативные `passive:false` + `preventDefault` для плавности — `266dd46`); свайп-влево удаляет позицию из корзины (`324b984`); перехват back-свайпа закрывает sheet вместо навигации назад (`30ab732`).
- Блокировка скролла body при открытом sheet — фикс iOS rubber-band (`605b8aa`).
- Нижний бар всегда виден (zIndex 99, GPU-слой `translateZ`) — `620a1e3`; форма «пилюли», полная ширина (`ff39f12`).
- Sheet стартует от низа хедера (top:104px), sticky «К каталогу» (`749d3db`, `ec73ea1`).
- `overflow-x: hidden` на html/body — нет горизонтального скролла (`a8e17a3`).
- Степпер по тапу **не** открывает корзину на мобиле (`087f2d9`).

## 5. Каталог и фильтры (дельта к CLAUDE.md от 04.06)

- **Подкатегория по умолчанию при загрузке — `paper` (Бумага)** (`91cc1ff`).
- Добавлена подкатегория **`dried` (Сухоцветы)**; sub-вкладки `artificial` — авто через data-driven (`f4d659e`).
- Фасеты перезагружаются при смене subgroup/volumeRanges; source-фильтр; subgroup/volume сужают детальные фасеты (`873d777`).
- Smart-чипы подсказок поиска: активное состояние + тоггл по клику (`b9836af`, `6e12835`).
- Сортировка по умолчанию — по убыванию остатка, новинки первыми (`aa196b5`).
- Ховер по карточке переключает все N фото (image_url + campaign_image_url + extra_images) — `fe73125`.
- Единица измерения «пог. м / шт» зависит от subcategory/unit (`cover_fabric`/`artificial_grass` → пог. м); корзина показывает правильную единицу (`51d9885`, `df5c4b8`).
- В AdminTable — кнопки-фильтры категорий (Срез/Горшок/Расходка), серверная фильтрация (`f9cdeaf`, `45c3fe0`).

## 6. Корзина и оформление

- Единый хук оформления **`useOrderCheckout`** — DetailPanel и CartSidebar используют один поток оплаты (`e292562`). Подробности потока — `docs/PAYMENTS.md`.
- Кнопка «повторить оплату» при отказе, плашка «резерв 30 мин».
- Шапка кабинета: счётчик активных заказов + сумма (`e877c84`).

## 7. Аутентификация / ввод телефона

- Поле телефона — **свободный ввод без маски**, backspace работает естественно (`c896408`).
- Поддержка международных номеров (`+375`, `+380` и т.д.): `normalizePhone`, форма входа, создание клиента — 11–15 цифр (`5278a11`, `29e5014`, `c2e71b7`).
- Профиль/смена PIN берут телефон из тела запроса, а не из сломанной cookie-сессии (`30fce12`).

## 8. Чат и уведомления

- Виджет Umnico: добавлен (`e742e90`), переключён на новый аккаунт (`444d17c`), грузится через `next/script afterInteractive` (`ada1bec`).
- **Уведомления только после подтверждения оплаты** (`0b68fc9`); WhatsApp клиенту об оплате заказа (`e2c37ab`). См. `docs/PAYMENTS.md`.
